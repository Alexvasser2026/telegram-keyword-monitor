САМАЯ ПРОСТАЯ ИНСТРУКЦИЯ — TELEGRAM MONITOR

Что получится: GitHub будет проверять новые сообщения в доступных группах примерно раз в 5 минут и присылать совпадения в ваш бот. Компьютер не нужен после первоначальной настройки. Запуски могут задерживаться.

ЧАСТЬ 1. ПОДГОТОВКА (один раз на компьютере)

1. Скачайте ZIP и распакуйте его через правую кнопку мыши → «Извлечь всё».
2. Установите Python отсюда: https://www.python.org/downloads/
   В установщике обязательно поставьте галочку «Add Python to PATH», если она есть.
3. Откройте https://my.telegram.org/apps, войдите по своему номеру и найдите API_ID и API_HASH. Сохраните их.
ВАЖНО: теперь API_HASH отображается при вводе в окне. Вводи его внимательно и не показывай окно другим людям.
4. В распакованной папке дважды нажмите «НАЧАТЬ_НАСТРОЙКУ.bat».
5. Следуйте подсказкам чёрного окна. Введите API_ID и API_HASH. Номер телефона вводить не нужно: программа откроет картинку с QR-кодом.
6. На телефоне откройте Telegram → Настройки → Устройства → Подключить устройство и отсканируйте QR-код на экране компьютера. Если Telegram попросит пароль двухэтапной проверки, введите его в чёрном окне.
7. После входа программа покажет длинную строку TELEGRAM_SESSION. Скопируйте её целиком в безопасное место. Когда нажмёте клавишу продолжения, будет показан ключ STATE_ENCRYPTION_KEY. Скопируйте и его. Это секретные данные. Никому их не передавайте.

ЧАСТЬ 2. ЗАГРУЗИТЬ ПРОГРАММУ НА GITHUB

7. Откройте https://github.com/ и создайте аккаунт или войдите.
8. Откройте https://github.com/new
9. В поле Repository name напишите telegram-keyword-monitor. Выберите Public и нажмите Create repository.
10. На странице репозитория нажмите Add file → Upload files.
11. На компьютере откройте распакованную папку проекта. Выделите ВСЁ ЕЁ СОДЕРЖИМОЕ (Ctrl+A), в том числе папку .github, и перетащите выделенное в область загрузки на GitHub. Важно: перетаскивайте содержимое папки, а не саму родительскую папку.
12. Внизу страницы нажмите Commit changes.

ЧАСТЬ 3. ДОБАВИТЬ ДАННЫЕ (СЕКРЕТЫ)

13. Откройте чат со своим существующим Telegram-ботом и отправьте /start.
14. Для токена бота откройте @BotFather в Telegram и используйте токен своего существующего бота. Не публикуйте токен.
15. Узнайте свой числовой Telegram ID через @userinfobot. Для личного чата с ботом это значение обычно подходит как BOT_CHAT_ID.
16. На странице своего репозитория GitHub откройте Settings → Secrets and variables → Actions.
17. Нажмите New repository secret и добавьте каждый пункт из таблицы отдельно:

Имя секрета             Значение
API_ID                  API_ID из my.telegram.org/apps
API_HASH                API_HASH из my.telegram.org/apps
TELEGRAM_SESSION        длинная строка из окна настройки
BOT_TOKEN               токен своего бота от @BotFather
BOT_CHAT_ID             ваш числовой Telegram ID
STATE_ENCRYPTION_KEY    ключ из окна настройки

Для каждого секрета: введите имя, вставьте соответствующее значение и нажмите Add secret. Не вставляйте все значения в одно поле.

ЧАСТЬ 4. ВКЛЮЧИТЬ И ПРОВЕРИТЬ

18. В репозитории откройте Settings → Actions → General.
19. Найдите Workflow permissions, выберите Read and write permissions и нажмите Save.
20. Откройте вкладку Actions. Слева нажмите Telegram keyword monitor. Нажмите Run workflow, затем ещё раз Run workflow.
21. Откройте запуск. Если всё прошло успешно, бот пришлёт сообщение «Мониторинг включён». При первом запуске старые сообщения не пересылаются.

ЧТО ВАЖНО ЗНАТЬ

• По умолчанию отслеживаются все доступные аккаунту группы и супергруппы. Каналы в этой версии не отслеживаются.
• Ищутся стандартные фразы: помочь, помоги, помогите, нужна помощь, кто может, подскажите и другие.
• После настройки компьютер можно выключить. GitHub запускает проверку примерно раз в 5 минут, но иногда бывают задержки.
• Для бесплатных запусков используйте Public-репозиторий. Исходный код там виден другим людям, поэтому никогда не кладите секреты в файлы — только в GitHub Secrets.
• TELEGRAM_SESSION даёт доступ к личному Telegram. Не отправляйте её никому и не загружайте в репозиторий.

ЕСЛИ НЕ РАБОТАЕТ

Вкладка Actions → откройте красный (ошибочный) запуск → нажмите шаг с ошибкой и прочитайте последнюю строку. Проверьте, что секреты названы точно как в таблице.
