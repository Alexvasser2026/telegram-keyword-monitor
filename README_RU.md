# Telegram Monitor — простая инструкция

1. Сначала откройте и прочитайте `GUIDE_SIMPLE_RU.txt`.
2. Установите Python.
3. Дважды нажмите `НАЧАТЬ_НАСТРОЙКУ.bat` — он установит библиотеки, поможет войти в Telegram по QR-коду (номер телефона вводить не нужно) и покажет два значения, которые нужно сохранить.
4. Затем выполните части 2–4 инструкции `GUIDE_SIMPLE_RU.txt`.

Не публикуйте TELEGRAM_SESSION, BOT_TOKEN, API_HASH или STATE_ENCRYPTION_KEY.
